# NHANES Hypertension Risk Prediction Model

## Overview

This project used NHANES 2015–2018 public health datasets to develop a logistic regression model predicting hypertension risk among women. The project focused on predictive analytics, data preprocessing, visualization, and dashboard communication.

## Tools Used

* Python
* Pandas
* Scikit-learn
* Tableau
* Logistic Regression
* NHANES Dataset

## Features

* Data cleaning and preprocessing
* Hypertension classification model
* ROC curve and confusion matrix evaluation
* Tableau dashboard visualization
* BMI and age group analysis

## Key Findings

The model achieved approximately 80% classification accuracy and demonstrated increasing hypertension prevalence with higher BMI and risk scores.

## Visualizations

* Confusion Matrix Heatmap
* BMI Distribution Histogram
* Hypertension by Age Group
* Interactive Tableau Dashboard

## Dataset

NHANES 2015–2016 and 2017–2018 public datasets from the CDC were used for analysis.
